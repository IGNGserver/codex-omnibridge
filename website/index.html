工作原理与安全边界

四个步骤说清楚：如何做到既不改客户端，又保住账号和密钥

所有转发与翻译都在你自己的设备本机完成，没有中间云端服务器经手你的代码和秘钥。

不改动日常 auth.json

安装、使用转发、换模型和卸载过程中都不会重写你的官方登录文件；如果主动切换官方账号，切换前会先留好受限权限备份快照。

外网强制加密与防跳转

发往公网的服务商地址强制要求 https://，拒绝未加密外网地址与本机内网元数据地址，同时禁用 307/308 重定向防秘钥泄露。

远程访问必须先设密码

默认只在 127.0.0.1:31828 本机可打开；只有设置 Argon2id 访问口令后，才允许局域网手机或平板连入控制面板。

# 1. 查看最简上手引导（或直接启动控制面板并自动打开网页端）
codex-mp setup
codex-mp web start --open

# 2. 通过本地网关启动你已经安装的官方 Codex CLI
codex-mp launch --codex-binary "$(command -v codex)"
# 1. 添加第三方服务商（以 OpenRouter 为例，Key 通过标准输入加密写入系统钥匙串）
printf '%s\n' "$OPENROUTER_API_KEY" | codex-mp provider add openrouter https://openrouter.ai/api/v1 --protocol chat-completions --api-key-stdin

# 2. 从接口拉取全部可用模型并写进 Codex /model 菜单
codex-mp provider fetch-models openrouter --all
codex-mp sync

# 3. 体检环境与路由状态
codex-mp doctor
# 1. 先配置网页访问口令（未设置口令前，软件会拒绝 0.0.0.0 外部绑定）
printf '%s\n' "$PANEL_PASSWORD" | codex-mp web password --stdin

# 2. 开启局域网访问权限并监听 31828 端口
codex-mp web remote --enable
codex-mp web start --allow-remote --port 31828
# 1. 继续之前中断的多模型会话（自动指定 OmniBridge 网关）
codex-mp resume --through-omnibridge <SESSION_ID>

# 2. 还原改写前的官方 Codex 配置（不删除本地应用数据）
codex-mp restore

# 3. 彻底卸载本地服务、注册配置与本软件写入的钥匙串条目
codex-mp uninstall
