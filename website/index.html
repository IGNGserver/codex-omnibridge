ZERO-TRACE CLI & RELEASE ARTIFACTS // 快速接入

管道安全传钥，三步开启多模型 Codex 工作流

提供跨平台单文件原生可执行程序 codex-mp（内嵌 Web 控制中心与系统托盘能力），零 Node / Python / WebKit 运行时依赖。

zsh / bash · 标准 stdin 传钥防 Shell 历史留痕 
# 1. 添加兼容网关（密钥经 stdin 写入系统钥匙串，不留命令历史）
printf '%s\n' "$OPENROUTER_API_KEY" | codex-mp provider add \
  --name openrouter \
  --base-url https://openrouter.ai/api/v1 \
  --protocol chat_completions \
  --api-key-stdin --discover

# 2. 可选接入本机离线 Ollama（环回地址自动免密 AuthStrategy::None）
codex-mp provider add --name ollama \
  --base-url http://127.0.0.1:11434/v1 \
  --auth-strategy none --discover

# 3. 合成兼容目录并启动官方 Codex（会话内直接输入 /model 热切换）
codex-mp setup
codex-mp launch

设计细节

  • --api-key-stdin 确保 API Key 既不会暴露在 ps aux 进程参数中，也不会写入 ~/.zsh_history。
  • --discover 自动请求上游 GET /models 并将模型启用注册至本地目录。
  • codex-mp launch 会自动确保后台 127.0.0.1:8787 路由守护就绪后再拉起官方 codex。
