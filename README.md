# Codex OmniBridge (模型切换与多模型桥接器)

> 让官方 Codex 能够自由切换第三方大模型（NewAPI、OneAPI、OpenRouter、本地大模型等），同时**绝不影响官方账号登录态**，保留原汁原味的官方订阅特权与生图等全部能力。

---

## 🌟 为什么需要 Codex OmniBridge？

在使用官方 Codex 时，你可能遇到过这些烦恼：
- 想用第三方的 DeepSeek、Gemini 3.8 Flash、Qwen、Claude 等模型，但切换配置后官方账号就退出了；
- 官方自带的生图、代码解释器或专属能力在切换后失效；
- 在同一个对话里，想中途换一个模型解答或补充，必须新建会话甚至改坏本地配置。

**Codex OmniBridge 正是为此而生：**
1. **官方账号完好保留**：你依然是官方登录状态，官方模型继续走官方订阅路线，生图与官方专属特权完全不受影响；
2. **同对话自由切模型**：同一个聊天窗口里，上一句用官方模型回答，下一句直接切到你的第三方模型，历史上下文平滑过渡；
3. **安全钥匙箱托管**：你的第三方 API Key 仅存放在系统安全的钥匙串中，绝不写入普通明文文件，绝不向官方泄露；
4. **轻量托盘与零残留卸载**：安装后在系统任务托盘常驻，退出后拦截功能即刻停用；如果你选择卸载，它会一键还原所有 Codex 原生设置，绝不留垃圾，绝不会“改坏”你的 Codex。

## 🚀 快速上手

### 1. 安装与启动
- 从 [Releases 页面](../../releases) 下载适合你系统的安装包；
- 运行安装程序后，软件会自动在任务托盘中静默运行；
- 单击托盘图标即可唤出控制面板。

### 2. 添加你的 AI 模型
在控制面板中，只需简单三步：
1. **添加服务商**：点击“添加服务商”，填入你的提供商名称、API 基础地址（Base URL）及 API 密钥；
2. **选择或添加模型**：点击“获取模型”，系统会自动拉取该服务商支持的模型列表，你可以挑选需要的模型一键添加，也可以手动输入自定义模型名称和上下文窗口大小；
3. **同步到 Codex**：点击面板上的“同步到 Codex”按钮。

### 3. 在 Codex 中享受多模型体验
打开 Codex（无论在 CLI 还是客户端），进入你的对话：
- 在模型选择列表或输入 `/model` 时，你会发现你添加的模型（如 `newapi/gemini-3.8-flash`）已经赫然在列！
- 官方模型（如 GPT-6-Astra、GPT-5.6-Terra、GPT-5.6-Luna）依然直接走你的官方订阅；
- 选中自定义模型时，OmniBridge 会在本地自动帮你进行安全转发，体验行云流水。

## 🖥️ 命令行与无界面（Headless）使用

如果你在没有图形界面的 Linux 服务器或更喜欢用终端：
```bash
# 1. 安全添加服务商与 API Key（支持从管道安全传入，不在终端历史留痕）
export NEWAPI_KEY='你的密钥'
printf '%s' "$NEWAPI_KEY" | codex-mp provider add NewAPI https://api.example.com/v1 --api-key-stdin

# 2. 导入模型
codex-mp provider fetch-models newapi --add qwen3.8

# 3. 同步至 Codex
codex-mp sync

# 4. 后台守护运行
codex-mp manager &
```

## 🛡️ 卸载与清理（零污染承诺）

如果你不再需要本程序，可以在设置中点击卸载，或在终端执行：
```bash
codex-mp-uninstall
```
程序会自动：
- 停止后台路由器；
- 恢复你最初的 `config.toml` 配置；
- 清理本地注册表与密钥；
- **你的 ChatGPT 登录状态、官方历史对话均 100% 保持原样，绝无污染。**

## 📋 常见问题 (FAQ)

**Q：使用自定义模型会消耗我的官方额度吗？**  
A：不会。请求官方模型时走你的官方账号；请求自定义模型时仅消耗你在对应服务商（如 NewAPI / OpenRouter）里的额度。

**Q：官方会不会知道我在用第三方模型？**  
A：不会。当分流到自定义模型时，OmniBridge 会自动在本地剔除官方特有的认证头与加密签名块，仅发送第三方需要的干净格式。
